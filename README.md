# pair-wise-yf-54 博物馆展品点交与布展条件核验

## 源提示词摘要
策展人、保管员、布展负责人和借展方从到场点交、环境条件检查、安装位置确认到闭展归还共同处理展品。系统记录条件、附件、风险等级、照片说明、处理意见和签字结果，差异项未解决时不能进入下一阶段，并支持大量展品与断网暂存。

## 技术栈
Vue 3 + TypeScript + Vite + Vuetify + Pinia + Vue Router + Axios + VueUse + VeeValidate + Zod + Vue I18n。

## 核验账模型
展品、柜位环境、差异项和分阶段签字连成一本账（`src/stores/exhibition.ts`）：

- **柜位共享读数**：温湿度、照度挂在柜位上，柜内展品共用；柜位带单调版本号。
- **签字带版本依据**：每条签字记录所依据的柜位版本与展品差异版本，有效性实时派生，不存"结论快照"。
- **柜位数据变化**：读数一变版本 +1，只作废依赖它的环境签字，点交签字与其他柜位照旧。
- **单件差异变化**：新增或确认解决差异只让该展品整组签字失效，同柜其他展品不受影响。
- **推进门禁**：推进在执行时重新校验，签字过期或未解决差异都会被拦下重核；已安装展品的现场位置写入后任何作废都不清除。
- **并发核验**：柜位核验提交携带打开时的版本号，两人同时提交同一柜位只有先到者生效，后到者收到版本冲突与受影响展品清单，整条提交不落地。
- **写盘出站队列**：变更先入待重试队列再写盘；写盘失败保留待重试项，恢复后只补未完成核验；签字以"展品/阶段/角色/类型/版本组合"为幂等键，重复提交不生成第二套。
- **核验账页签**：签字、作废、柜位核验、版本冲突、推进、拦下重核、写盘失败与恢复全部逐条入账。

## 界面
- **展品点交**：大列表 + 详情（当前阶段所需签字、签字历史、差异项、推进门禁）。
- **柜位环境**：柜位卡片展示共享读数、版本、环境签字有效/作废统计；可提交柜位核验或模拟另一负责人并发提交。
- **差异项**：登记/确认解决差异，附整组失效提示。
- **核验账**：全量事件流水。
- 顶栏可开启"模拟写盘故障"演示待重试与恢复补写。

## 启动
```bash
npm install
npm run dev
```

## 校验
```bash
npm run verify   # 无头断言：作废级联、推进门禁、并发冲突、写盘重试与幂等
npm run build    # 类型检查 + 构建
```
